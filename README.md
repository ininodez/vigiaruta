# VigíaRuta

Detector de somnolencia para choferes que corre en el navegador (cámara de celular o laptop). Todo se procesa en el dispositivo; el video no sale del equipo.

App: https://ininodez.github.io/vigiaruta/

Pruebas de la lógica: `node test_detector.mjs`

Es una ayuda, no reemplaza el descanso ni un sistema certificado.
